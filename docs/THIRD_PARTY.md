# Third-party icons

Generic picker icons use the AndroidX Material icons library (Apache License 2.0). Source: https://github.com/google/material-design-icons

Kairo's launcher and notification marks are original. The current picker bundles no third-party service logos. Before adding one, document the official asset source, permission for use and redistribution, applicable brand guidelines, and any required attribution here. Use a generic icon when these terms are unclear. Images selected by users are stored locally and travel with their backups.
